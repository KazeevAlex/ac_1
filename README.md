# Проект "Планировщик обратных вызовов"

Этот проект представляет собой простой, потокобезопасный и эффективный механизм планирования обратных вызовов (callback).

## Ключевые компоненты

Реализация разделена на два основных класса: `BaseCallbackSchedulerImpl` и `BaseCallbackSchedulerWorkerImpl`.

### `BaseCallbackSchedulerImpl.java`

Этот класс предоставляет публичный API для планирования обратных вызовов.

**Преимущества:**

*   **Четкое разделение ответственности:** Класс отвечает только за прием и валидацию задач, делегируя их выполнение `CallbackSchedulerWorker`. Это упрощает код и делает его более модульным.
*   **Простой и понятный API:** Предлагает простой метод `schedule(Runnable callback, Instant when)` для использования.
*   **Надежность:** Проверяет корректность аргументов (например, что время выполнения находится в будущем), что предотвращает ошибки во время выполнения.

### `BaseCallbackSchedulerWorkerImpl.java`

Это фоновый исполнитель (worker), отвечающий за выполнение обратных вызовов в назначенное время.

**Преимущества:**

*   **Потокобезопасность:** Использует `ReentrantLock` для обеспечения безопасной обработки одновременной отправки обратных вызовов из разных потоков.
*   **Эффективное ожидание:** Реализует эффективную стратегию ожидания с использованием `ReentrantLock` и `Condition`. Вместо активного ожидания (busy-waiting), поток исполнителя "засыпает" до тех пор, пока не будет отправлена новая задача или не наступит время выполнения следующего запланированного вызова. Это значительно снижает загрузку процессора.
*   **Приоритетное выполнение:** Использует `PriorityQueue` для управления запланированными задачами. Это гарантирует, что обратные вызовы всегда выполняются в хронологическом порядке их запланированного времени.
*   **Корректное завершение работы:** Поток исполнителя может быть корректно остановлен через механизм прерывания (`interrupt`), что обеспечивает правильное освобождение ресурсов.
